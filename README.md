Şu anda üzerinde çalıştığım ve yayına aldığım proje:

🚀 Yıldız Raketler (https://yildizraketler.com)

Açıklama: İstanbul merkezli bir masa tenisi spor kulübü için geliştirilmiş kurumsal web sitesi. Site, kulübün grup/özel dersleri, yaz okulu, kampları ve turnuvaları gibi faaliyetleri hakkında bilgi sunar. Admin paneli üzerinden içerik yönetimi (duyurular, sayfalar, vb.) ve iletişim formu mesajlarının takibini sağlar. Google Places API ile entegre edilerek, işletmenin gerçek Google yorumları dinamik olarak sitede gösterilir.

Teknolojiler: React, Vite, Firebase (Authentication, Firestore, Storage, Hosting, Cloud Functions).

Durum: Canlıda!
